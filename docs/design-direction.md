# Design Direction

## Overall Mood And Personality

The Rice Cricket Club website should feel:

- Premium
- Collegiate
- Energetic
- Warm
- Credible
- Image-led

The ideal reference point is not a generic student club template and not a chaotic sports microsite. The goal is something closer to a modern editorial athletics presentation: strong type, cinematic photography, disciplined grids, and a sense of real momentum.

## Visual Personality

The visual system should communicate three qualities at once:

- `Prestige`: the club belongs in a serious university context
- `Warmth`: new students should feel welcome rather than intimidated
- `Energy`: cricket should feel active, social, and exciting

The design should never sacrifice clarity in pursuit of spectacle.

## UI Style

Recommended UI characteristics:

- Full-bleed image moments used intentionally
- Strong vertical rhythm and generous whitespace
- Clear section framing with editorial labels and strong headings
- Clean cards with subtle depth, not glossy app-style tiles
- Accent usage that feels deliberate rather than decorative

Avoid:

- Loud sports-scoreboard clutter
- Startup-style gradient excess
- Thin, sterile institutional minimalism
- Template-looking hero blocks with generic stock overlays

## Layout Philosophy

The site should alternate between:

- Immersive visual sections that build emotion and identity
- Structured content bands that provide clarity, proof, and calls to action

This rhythm is important. Too many image-heavy sections in a row will feel messy. Too much structured text in a row will flatten the energy.

Recommended layout habits:

- Use asymmetry carefully to create character
- Keep content widths disciplined for readability
- Let the homepage breathe rather than overfilling it
- Use section transitions to give the site a crafted editorial pace

## Image Treatment

Photography should do a large share of the recruiting work.

Prioritize:

- Action shots from matches and practices
- Team huddles and candid social moments
- Images with visible emotion, movement, and connection
- Contextual shots that place the club within the Rice environment

Avoid:

- Random uncaptioned image dumps
- Overly dark overlays that flatten the photography
- Low-resolution or inconsistent crops
- Stock-looking sports imagery that is not actually the club

Image styling recommendations:

- Use bold crops and let some images run large
- Favor natural color treatment over aggressive filters
- Keep captions available for gallery contexts and storytelling pages

## Typography Recommendations

## Top Recommendation

### `Barlow Condensed` + `Source Serif 4`

- `Barlow Condensed` gives headlines athletic confidence and presence without looking cartoonish
- `Source Serif 4` adds academic warmth and strong long-form readability
- Together they create a useful tension between sport and institution

This pairing best fits the site's dual identity: competitive student organization and credible university presence.

## Backup Option 1

### `Sora` + `Crimson Pro`

- `Sora` feels contemporary and polished
- `Crimson Pro` gives the body copy literary warmth
- This option works well if the design later leans slightly more modern and refined, and slightly less varsity

## Backup Option 2

### `Archivo` + `Literata`

- `Archivo` is sturdy and legible with a more grounded institutional feel
- `Literata` supports narrative pages, captions, and longer editorial content
- This option is useful if brand review pushes the design toward more formal clarity

## High-Level Typography System

| Style | Role | Direction |
| --- | --- | --- |
| Hero headings | First-impression headlines | Large, compressed, bold, and confident |
| Section headings | Major content transitions | Strong but calmer than hero headings |
| Body text | Main explanatory copy | Comfortable reading size with generous line height |
| Labels | Eyebrows, metadata, small UI labels | Compact, uppercase or tracked text used sparingly |
| Captions | Supporting image or gallery context | Smaller serif or balanced text style with strong contrast |
| Stat numbers | Milestones and proof points | Oversized, bold, and highly scannable |

## Color And Branding Direction

The palette should feel collegiate and premium, with a restrained sense of athletic energy.

### Primary Color Direction

- Deep Rice-adjacent blue for authority and seriousness
- Use as the main anchor color for headings, dark surfaces, and navigation moments

### Accent Color Direction

- Restrained turf green for active or athletic emphasis
- Use sparingly for highlights, status accents, or proof-driven moments

### Neutral Palette Direction

- Warm off-white, parchment-like backgrounds
- Layered slate and charcoal neutrals for text and structure
- Avoid stark pure white paired with oversaturated accents

### Optional Starting Token Direction

These are provisional starting tones, not locked brand colors:

- Midnight blue: `#16324f`
- Slate ink: `#22313f`
- Warm paper: `#f4f0e7`
- Deep charcoal: `#171c21`
- Turf green accent: `#456b52`

Any final color values should still be checked for accessibility contrast and any relevant Rice brand constraints.

## How The Palette Should Feel

The palette should make the site feel:

- Serious enough for administrators
- Warm enough for students
- Distinct enough to avoid a template feel
- Energetic enough to support action photography and athletic storytelling

It should not feel:

- Childish
- Neon
- Hyper-saturated
- Dark and brooding for no reason

## Interaction And Motion Recommendations

Motion should support hierarchy, delight, and clarity. It should not call attention to itself.

| Interaction | Recommendation | Why |
| --- | --- | --- |
| Smooth scrolling | Use sparingly | Helpful for anchor links, but should respect reduced-motion preferences |
| Reveal-on-scroll | Recommended | Good for pacing and hierarchy when kept subtle |
| Hover microinteractions | Recommended | Adds polish on cards, links, and media without overwhelming the experience |
| Gallery lightbox | Recommended | Adds real value for an image-forward site if keyboard and reduced-motion support are built in |
| Animated counters | Use sparingly | Useful for a proof strip, but only if the numbers matter and the animation is restrained |
| Timeline animation | Use sparingly | Can help About or Vision feel alive, but should not become a gimmick |
| Subtle parallax | Optional and restrained | Can deepen hero sections, but risks distraction and performance issues if overused |
| SVG illustration animation | Usually avoid | Low value unless a specific branded graphic system is later introduced |
| Loading transitions | Keep minimal | Static content should feel fast; do not invent delay for style |
| Page transitions | Avoid in v1 | Little strategic benefit and easy to make the site feel overproduced |
| Constant background animation | Avoid | Distracts from photography, harms readability, and tends to age poorly |

## Accessibility Direction

All visual recommendations should assume:

- Semantic structure
- Visible focus states
- Keyboard navigability
- Strong contrast ratios
- Reduced-motion support
- Alt text and caption discipline for media
- Clear content hierarchy on both desktop and mobile

The site should feel premium because it is thoughtful, not because it hides information behind motion or visual tricks.

## Visual Directions To Avoid

- Generic student club site aesthetics with interchangeable sections and default fonts
- ESPN-style layouts full of dense score blocks and visual noise
- Startup landing page tropes that do not fit a university club
- Excessive gradient backgrounds or glossy neon accents
- Heavy-handed faux prestige design that feels stiff and unwelcoming
